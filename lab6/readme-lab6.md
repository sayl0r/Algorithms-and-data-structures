## Теоретическое обоснование

**Рекурсия** — это метод, при котором функция вызывает саму себя для решения подзадач меньшего размера. Любая рекурсивная функция должна иметь:
1. **Базовый случай** — условие остановки (например, `if (n == 0) return 1;`).
2. **Шаг рекурсии** — вызов функции с меньшим параметром (например, `return n * factorial(n - 1);`).

**Простые сортировки** имеют сложность O(n²) в среднем и худшем случаях, но O(1) по памяти (работают in-place). 
*   *Пузырьковая* — сравнивает соседние элементы и меняет их местами.
*   *Вставками* — берет элемент и вставляет его на нужное место в уже отсортированной левой части.
*   *Выбором* — ищет минимальный элемент и ставит его в начало.

#include <iostream>
#include <string>

using namespace std;

// РЕКУРСИВНЫЕ АЛГОРИТМЫ (Вариант 12)

// Задача 1: Факториал числа
long long fact(int n) { return (n <= 1) ? 1 : n * fact(n - 1); }

// Задача 2: Числа Фибоначчи
int fib(int n) { return (n <= 1) ? n : fib(n - 1) + fib(n - 2); }

// Задача 3: Проверка сбалансированности скобок
bool checkBrackets(string s, int i = 0, int bal = 0) {
    if (bal < 0) return false;
    if (i == s.length()) return bal == 0;
    if (s[i] == '(' || s[i] == '[' || s[i] == '{') return checkBrackets(s, i + 1, bal + 1);
    if (s[i] == ')' || s[i] == ']' || s[i] == '}') return checkBrackets(s, i + 1, bal - 1);
    return checkBrackets(s, i + 1, bal);
}

// Задача 4: Генерация всех комбинаций
void genComb(int n, string cur = "") {
    if (cur.length() == n) { cout << cur << " "; return; }
    genComb(n, cur + "0"); genComb(n, cur + "1");
}

// ПРОСТЫЕ СОРТИРОВКИ

// 1. Пузырьковая сортировка (Bubble Sort)
void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool sw = false;
        for (int j = 0; j < n - i - 1; j++) {
            if (a[j] > a[j + 1]) { swap(a[j], a[j + 1]); sw = true; }
        }
        if (!sw) break; // Оптимизация
    }
}

// 2. Сортировка выбором (Selection Sort)
void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[minIdx]) minIdx = j;
        }
        if (minIdx != i) swap(a[i], a[minIdx]);
    }
}

// 3. Рекурсивная сортировка вставками (Доп. задание 12 варианта)
void insertionSortRec(int a[], int n) {
    if (n <= 1) return;
    insertionSortRec(a, n - 1);
    int last = a[n - 1], j = n - 2;
    while (j >= 0 && a[j] > last) { 
        a[j + 1] = a[j]; 
        j--; 
    }
    a[j + 1] = last;
}

// Вспомогательная функция для вывода массива
void print(int a[], int n) {
    for (int i = 0; i < n; i++) cout << a[i] << " ";
    cout << "\n";
}

int main() {
    // Тест рекурсивных алгоритмов
    cout << "RECURSION\n";
    cout << "Fact(5): " << fact(5) << "\n";
    cout << "Fib(10): " << fib(10) << "\n";
    cout << "Brackets '{[()]}': " << (checkBrackets("{[()]}") ? "true" : "false") << "\n";
    cout << "Combinations(2): "; genComb(2); cout << "\n\n";

    // Тест сортировок
    cout << "SORTING\n";
    int a1[] = {5, 2, 9, 1, 4}, a2[] = {5, 2, 9, 1, 4}, a3[] = {5, 2, 9, 1, 4};
    int n = 5;

    // 1. Пузырьковая
    bubbleSort(a1, n);        
    cout << "1. Bubble Sort:    "; print(a1, n);

    // 2. Выбором
    selectionSort(a2, n);     
    cout << "2. Selection Sort: "; print(a2, n);

    // 3. Рекурсивная вставками (Доп. задание)
    insertionSortRec(a3, n);  
    cout << "3. Insertion Sort (Recursive): "; print(a3, n);

    return 0;
}

## Контрольные вопросы

1. **Что такое рекурсия? Из каких компонентов состоит рекурсивная функция?**
   Это вызов функцией самой себя. Состоит из базового случая (условие остановки) и шага рекурсии (вызов с меньшим параметром).

2. **Что такое базовый случай рекурсии? Почему он важен?**
   Это условие, при котором рекурсия прекращается. Без него функция будет вызывать себя бесконечно, что приведет к переполнению стека (Stack Overflow).

3. **Чем отличается прямая рекурсия от косвенной?**
   Прямая: функция вызывает саму себя. Косвенная: функция A вызывает функцию B, а та в свою очередь вызывает A.

4. **Что такое хвостовая рекурсия? В чём её преимущество?**
   Это рекурсия, где вызов функции является последней операцией. Преимущество: умные компиляторы могут оптимизировать её в обычный цикл, экономя память стека.

5. **Какова временная сложность рекурсивного вычисления чисел Фибоначчи? Почему?**
   O(2ⁿ) — экспоненциальная. Потому что каждый вызов порождает два новых, и многие значения вычисляются заново.

6. **Как можно оптимизировать рекурсивное вычисление Фибоначчи?**
   Использовать мемоизацию (кэширование уже вычисленных значений) или переписать на итеративный цикл.

7. **В чём отличие рекурсивной реализации от итеративной?**
   Рекурсивная тратит память на стек вызовов (риск переполнения), но код часто короче и читаемее. Итеративная экономит память и обычно работает быстрее.

8. **Какова сложность пузырьковой сортировки? Когда она становится O(n)?**
   В среднем и худшем O(n²). Становится O(n), если массив уже отсортирован (благодаря флагу `swapped`, цикл прерывается после первого прохода).

9. **Чем сортировка вставками отличается от сортировки выбором?**
   Вставками ищет место для текущего элемента в отсортированной части, сдвигая элементы. Выбором ищет минимум в неотсортированной части и меняет его с первым элементом.

10. **Какая из простых сортировок является устойчивой? Что это значит?**
    Пузырьковая и вставками. Устойчивость значит, что одинаковые элементы сохраняют свой первоначальный порядок относительно друг друга.

11. **Какая из простых сортировок работает лучше на почти отсортированных данных?**
    Сортировка вставками (и пузырьковая с оптимизацией). Они работают за O(n), так как требуется минимум перестановок.

12. **Как реализовать пузырьковую сортировку с оптимизацией?**
    Добавить флаг `swapped`. Если за проход не было ни одного обмена, значит массив уже отсортирован и можно завершать цикл.

13. **Что такое рекурсивный поиск с возвратом (backtracking)?**
    Метод, при котором мы идем вглубь, а если зашли в тупик — возвращаемся на шаг назад и пробуем другой путь (как в обходе лабиринта).

14. **Как рекурсивно обойти лабиринт?**
    Проверить текущую клетку (стена/финиш). Пометить как посещенную. Рекурсивно вызвать функцию для соседних клеток (верх, низ, лево, право).

15. **Какова сложность Ханойских башен? Сколько ходов нужно для перемещения n дисков?**
    Сложность O(2ⁿ). Количество ходов равно 2ⁿ - 1.
