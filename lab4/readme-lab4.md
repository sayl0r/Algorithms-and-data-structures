## Теоретическое обоснование

**Связный список** — это структура данных, в которой элементы (узлы) не хранятся в памяти непрерывно. Каждый узел содержит сами данные и указатель(и) на следующий (и/или предыдущий) узел.
*   В **односвязном списке** каждый узел хранит указатель только на следующий элемент. Это экономит память, но позволяет двигаться только в одном направлении.
*   В **двусвязном списке** каждый узел хранит указатели и на следующий, и на предыдущий элемент. Это позволяет быстро удалять элементы с конца и обходить список в обратном порядке.
*   **Кольцевой (циклический) список** — это разновидность списка, в которой последний узел ссылается не на `nullptr`, а на первый узел (голову), образуя замкнутый круг. Это удобно для циклического перебора элементов.

## Ключевые фрагменты кода

**Реализация односвязного списка (SinglyLinkedList):**

```cpp
#include <iostream>

class SinglyLinkedList {
private:
    struct Node {
        int data;
        Node* next;
        Node(int val) : data(val), next(nullptr) {}
    };
    Node* head;
    Node* tail;

public:
    SinglyLinkedList() : head(nullptr), tail(nullptr) {}
    
    // Деструктор для очистки памяти
    ~SinglyLinkedList() {
        Node* current = head;
        while (current != nullptr) {
            Node* next = current->next;
            delete current;
            current = next;
        }
    }

    void push_back(int val) {
        Node* newNode = new Node(val);
        if (!head) {
            head = tail = newNode;
        } else {
            tail->next = newNode;
            tail = newNode;
        }
    }

    void print() {
        Node* current = head;
        while (current != nullptr) {
            std::cout << current->data << " -> ";
            current = current->next;
        }
        std::cout << "nullptr\n";
    }
};
```

**Реализация двусвязного кольцевого списка (DoublyLinkedList — Вариант 12):**

```cpp
class DoublyLinkedList {
private:
    struct Node {
        int data;
        Node* next;
        Node* prev;
        Node(int val) : data(val), next(nullptr), prev(nullptr) {}
    };
    Node* head;

public:
    DoublyLinkedList() : head(nullptr) {}
    
    // Деструктор для кольцевого списка (используем do-while)
    ~DoublyLinkedList() {
        if (!head) return;
        Node* current = head;
        do {
            Node* next = current->next;
            delete current;
            current = next;
        } while (current != head);
    }

    // В кольцевом списке push_back добавляет элемент перед головой
    void push_back(int val) {
        Node* newNode = new Node(val);
        if (!head) {
            head = newNode;
            head->next = head;
            head->prev = head;
        } else {
            Node* tail = head->prev; // Последний элемент
            newNode->next = head;
            newNode->prev = tail;
            tail->next = newNode;
            head->prev = newNode;
        }
    }

    void print() {
        if (!head) {
            std::cout << "List is empty\n";
            return;
        }
        Node* current = head;
        do {
            std::cout << current->data << " <-> ";
            current = current->next;
        } while (current != head);
        std::cout << "(return to head: " << head->data << ")\n";
    }
};
```

## Контрольные вопросы

1. **Чем связный список отличается от динамического массива?**
   Динамический массив (например, `std::vector`) хранит элементы в памяти непрерывно (одним куском), что дает быстрый доступ по индексу O(1), но при вставке/удалении в середину требует сдвига всех элементов O(n). Связный список хранит элементы разрозненно (узлами), связанными указателями. В нем вставка/удаление (если известен узел) происходит за O(1), но доступ по индексу требует перебора всех предыдущих элементов за O(n).

2. **Какие операции в односвязном списке выполняются за O(1)?**
   Вставка в начало (`push_front`), удаление из начала (`pop_front`), а также вставка в конец (`push_back`), если реализован и поддерживается указатель на хвост (`tail`).

3. **Почему удаление из конца односвязного списка требует O(n) времени?**
   Потому что в односвязном списке указатели идут только вперед. Чтобы удалить последний элемент, нам нужно изменить указатель `next` у предпоследнего элемента на `nullptr`. Но мы не знаем, где находится предпоследний узел, поэтому вынуждены пробежать весь список от начала (головы) до предпоследнего элемента.

4. **Какие преимущества даёт хранение указателя tail в односвязном списке?**
   Это позволяет выполнять добавление элемента в конец списка (`push_back`) за константное время O(1). Без указателя на хвост нам пришлось бы каждый раз проходить весь список до конца, чтобы найти последний узел, что заняло бы O(n).

5. **Чем двусвязный список отличается от односвязного?**
   В двусвязном списке каждый узел содержит два указателя: на следующий элемент (`next`) и на предыдущий (`prev`). Это позволяет обходить список в обоих направлениях, но требует больше памяти на хранение указателей.

6. **Какие операции в двусвязном списке выполняются быстрее, чем в односвязном?**
   Удаление с конца (`pop_back`) — за O(1), так как мы можем сразу перейти от хвоста к предпоследнему элементу по указателю `prev`. Также быстрее выполняется удаление конкретного узла, если у нас есть указатель на него (не нужно искать предыдущий узел).

7. **Что такое «голова» (head) и «хвост» (tail) списка?**
   `head` — это указатель на самый первый узел списка (с него начинается обход). `tail` — это указатель на самый последний узел списка (его указатель `next` обычно равен `nullptr`, либо в циклическом списке указывает обратно на `head`).

8. **Как удалить узел из середины односвязного списка?**
   Для этого нужен указатель на узел, стоящий *перед* удаляемым. Алгоритм: берем указатель `prev` (предыдущий) и меняем его `next` на узел, следующий за удаляемым: `prev->next = toDelete->next`. Затем удаляем сам узел `delete toDelete`.

9. **Как удалить узел из середины двусвязного списка? Почему это проще?**
   В двусвязном списке у нас уже есть указатель на сам удаляемый узел (назовем его `node`), и нам не нужно искать предыдущий. Мы просто перенаправляем указатели соседей друг на друга: `node->prev->next = node->next` и `node->next->prev = node->prev`, после чего удаляем узел. Это проще, так как не требуется дополнительный проход по списку для поиска предыдущего элемента.

10. **Что произойдёт, если забыть обновить tail при удалении?**
    Если удалить последний элемент (хвост), но не обновить указатель `tail`, он будет указывать на уже освобожденную область памяти (висячий указатель). При следующей попытке добавить элемент в конец (`push_back`) программа попытается обратиться к удаленной памяти, что приведет к неопределенному поведению или сегфолту (падению программы).

11. **Как реализовать реверс односвязного списка?**
    Нужно идти по списку, сохраняя три указателя: `prev` (предыдущий), `current` (текущий) и `next` (следующий). На каждом шаге меняем направление указателя текущего узла на предыдущий (`current->next = prev`), затем сдвигаем всю тройку указателей на шаг вперед. В конце присваиваем `head = prev`.

12. **Как обнаружить цикл в связном списке?**
    Самый популярный способ — «Алгоритм Флойда» (черепаха и заяц). Запускаем два указателя: медленный (делает 1 шаг) и быстрый (делает 2 шага). Если в списке есть цикл, быстрый указатель рано или поздно догонит медленный (они встретятся на одном узле). Если быстрый дойдет до `nullptr`, значит цикла нет.

13. **В каких случаях стоит использовать список вместо массива?**
    Список стоит использовать, когда:
    *   Часто происходят вставки и удаления элементов в начале или середине структуры.
    *   Заранее неизвестно точное количество элементов (хотя вектор с этим тоже справляется).
    *   Требуется часто перестраивать последовательность (например, слияние списков).
    *   Важна скорость вставки O(1), а не скорость доступа по индексу O(1).

14. **Какая дополнительная память требуется для каждого узла списка?**
    Для односвязного списка: память под сами данные (`data`) + один указатель (`next`), обычно 8 байт на 64-битной системе.
    Для двусвязного: данные + два указателя (`next` и `prev`), то есть 16 байт на 64-битной системе.

15. **Почему доступ по индексу в списке имеет сложность O(n)?**
    Потому что узлы списка хранятся в памяти не подряд, и мы не можем вычислить адрес нужного элемента математически (как в массиве: `адрес_начала + индекс * размер_типа`). Мы вынуждены каждый раз начинать с головы (`head`) и переходить по указателям `next`, пока не дойдем до нужного индекса. В худшем случае (поиск последнего элемента) придется сделать `n` шагов.
