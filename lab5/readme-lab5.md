## Теоретическое обоснование

**Стек** работает по принципу LIFO (Last In — First Out). Элементы добавляются и извлекаются только с одного конца (вершины). Аналогия — стопка тарелок.

**Очередь** работает по принципу FIFO (First In — First Out). Элементы добавляются в конец, а извлекаются из начала. Аналогия — очередь в магазине.

**Дек (Double-Ended Queue)** — двусторонняя очередь, позволяющая добавлять и удалять элементы как с начала, так и с конца за O(1).

**Приоритетная очередь** извлекает элементы не по порядку добавления, а по их приоритету. Чаще всего реализуется на основе двоичной кучи (binary heap), где корневой элемент всегда имеет максимальный (или минимальный) приоритет.

## Ключевые фрагменты кода

**1. Стек с `getMiddle()`:**
```cpp
#include <iostream>
#include <vector>

class CustomStack {
    std::vector<int> data;
public:
    void push(int val) { data.push_back(val); }
    void pop() { if (!data.empty()) data.pop_back(); }
    int getMiddle() {
        if (data.empty()) return -1;
        return data[data.size() / 2]; // Доступ к середине за O(1)
    }
};
```

**2. Очередь (разделение на чётные/нечётные позиции):**

```cpp
void splitQueue() {
    std::queue<int> q, evenPos, oddPos;
    for (int i = 1; i <= 6; ++i) q.push(i * 10); // 10, 20, 30, 40, 50, 60

    int pos = 1;
    while (!q.empty()) {
        int val = q.front(); q.pop();
        if (pos % 2 == 0) evenPos.push(val);
        else oddPos.push(val);
        pos++;
    }
    // Дальше вывод oddPos и evenPos...
}
```

**3. Дек с insertAt(index):**

```cpp
#include <deque>

void dequeInsert() {
    std::deque<int> dq = {10, 20, 40, 50};
    int index = 2; // Вставка на 3-ю позицию
    int value = 30;
    
    // std::deque::insert принимает итератор
    dq.insert(dq.begin() + index, value); 
}
```

**4. Проверка массива на двоичную кучу (max-heap):**

```cpp
#include <vector>

bool isMaxHeap(const std::vector<int>& arr) {
    int n = arr.size();
    // Проверяем, что каждый родитель больше своих детей
    for (int i = 0; i <= (n - 2) / 2; ++i) {
        int left = 2 * i + 1;
        int right = 2 * i + 2;
        if (left < n && arr[i] < arr[left]) return false;
        if (right < n && arr[i] < arr[right]) return false;
    }
    return true;
}
```

## Контрольные вопросы

1. **В чём заключается принцип работы стека (LIFO)?**
   LIFO (Last In, First Out) — последним пришел, первым ушел. Добавление (`push`) и удаление (`pop`) происходят только с вершины стека.

2. **В чём заключается принцип работы очереди (FIFO)?**
   FIFO (First In, First Out) — первым пришел, первым ушел. Элементы добавляются в конец (`enqueue`), а извлекаются из начала (`dequeue`).

3. **Чем дек отличается от обычной очереди?**
   В обычной очереди добавление возможно только в конец, а удаление — только из начала. В деке (двусторонней очереди) можно добавлять и удалять элементы с обоих концов.

4. **Что такое приоритетная очередь? Где она применяется?**
   Это структура данных, где каждый элемент имеет приоритет. Извлекается всегда элемент с наивысшим приоритетом. Применяется в операционных системах (планировщики задач), алгоритмах на графах (Дейкстра), сжатии данных (Хаффман).

5. **Как реализовать стек на основе динамического массива?**
   Нужно хранить массив и индекс верхнего элемента (`topIndex`). При добавлении `topIndex` увеличивается, при удалении — уменьшается. При переполнении массив расширяется (обычно в 2 раза).

6. **Как реализовать очередь на основе кольцевого буфера?**
   Используется массив фиксированного размера и два индекса: `head` (начало) и `tail` (конец). При добавлении/удалении индексы сдвигаются по кругу с помощью операции остатка от деления `(index + 1) % capacity`.

7. **Почему приоритетную очередь обычно реализуют на куче?**
   Куча (heap) позволяет выполнять вставку и удаление максимального элемента за O(log n), а получение максимума — за O(1). Это оптимальный баланс по сравнению с обычным массивом или списком.

8. **Какова сложность операций push и pop в стеке?**
   O(1) (константная), так как мы работаем только с концом массива/списка.

9. **Какова сложность операций enqueue и dequeue в очереди?**
   O(1), если используется кольцевой буфер или связный список с указателем на хвост.

10. **Какова сложность операций в приоритетной очереди? Почему?**
    `push` и `pop` — O(log n), потому что после добавления или удаления элемента нужно восстановить свойства кучи (просеять элемент вверх или вниз по дереву). `top` — O(1).

11. **Как проверить правильность расстановки скобок с помощью стека?**
    Идем по строке. Если видим открывающую скобку — кладем в стек. Если закрывающую — достаем из стека и проверяем, совпадают ли они. В конце стек должен быть пуст.

12. **Как реализовать очередь на двух стеках? Какова сложность?**
    Один стек для добавления (`in`), второй для извлечения (`out`). При `dequeue`, если стек `out` пуст, перекладываем все элементы из `in` в `out`. Амортизированная сложность — O(1) на операцию.

13. **Как реализовать дек на основе двусвязного списка?**
    Создать узлы с указателями `next` и `prev`. Хранить указатели на `head` и `tail`. Добавление и удаление с обоих концов сводится к переназначению указателей за O(1).

14. **Как реализовать дек на основе кольцевого буфера?**
    Использовать массив, где `head` и `tail` движутся навстречу друг другу (или в одном направлении по кругу). Нужно аккуратно обрабатывать переполнение и опустошение.

15. **Как реализовать стек с поддержкой получения минимума за О(1)?**
    Использовать два стека: основной и стек минимумов. При каждом `push` в стек минимумов кладется минимум из текущего значения и вершины стека минимумов. При `pop` удаляем из обоих.
